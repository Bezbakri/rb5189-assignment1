# Contributing Policy

## Creating Issues

For code change issues, please specify a line number, and if possible, add suggested fixes.

For new features, add \[SUGGESTION\] to the start of the issue title.

For vulnerabilities, add \[VULNERABILITY\] to the start of the issue title.

## Creating Pull Requests

If you are pushing new changes to the repository, please start by opening an issue discussing what changes you would like to make to the code. After the issue is discussed, you can open a pull request for the suggested changes. Make sure that the code has been formatted using Black, and that flake8 and mypy report no issues with the proposed changes. Add test cases for major code changes and test it with pytests.
