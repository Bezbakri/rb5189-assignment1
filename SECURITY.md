# Security Policy

## Supported Versions

As the project is only on version 0.1.x, it is the only version that is supported.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

To report a vulnerability, send me a message on discord at @bezbakri detailing the vulnerability. After 30 days of sending this message, regardless of whether the issue was patched or not, open an issue on the [GitHub Repository of this project](https://github.com/Bezbakri/rb5189-assignment1). The status of the vulnerability will then be commented on the issue.
