# Security Policy

## Supported Versions

As the project is only on version 0.1.x, it is the only version that is supported.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

In order to report a vulnerability, please open an issue on the [GitHub Repository of this project](https://github.com/Bezbakri/rb5189-assignment1).

The vulnerability will be accepted or declined based on the status of the issue opened on GitHub.
